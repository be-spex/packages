be-spex packages

APT repository for the be-spex applications on current Debian, Ubuntu and Linux Mint (amd64; HatRack also arm64).

Set up once

curl -fsSLO https://be-spex.github.io/packages/be-spex-archive-keyring.deb
sudo apt install ./be-spex-archive-keyring.deb
sudo apt update

The package installs the signing key to /usr/share/keyrings/ and the source /etc/apt/sources.list.d/be-spex.sources. After that, updates arrive with sudo apt upgrade.

Install

sudo apt install marq xaq maillet hatrack pockettray   # any of them

Manual setup

curl -fsSL https://be-spex.github.io/packages/be-spex-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/be-spex-archive-keyring.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/be-spex.sources <<'EOF'
Types: deb
URIs: https://be-spex.github.io/packages
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/be-spex-archive-keyring.gpg
EOF
sudo apt update
